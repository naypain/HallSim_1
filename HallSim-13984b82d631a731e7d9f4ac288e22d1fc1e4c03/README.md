# Hall Thruster Simulation

### Instructions

1. Clone repo

```bash
git clone https://github.com/naypain/HallSim
```


2. Create virtual environment and install dependencies

```bash
cd HallSim
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
3. Run application

```bash
streamlit run src/HallSim.py
```
